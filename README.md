# foxkit · 专用浏览器工具

给日常上网准备的一个独立小工具：一个专用的 Firefox 浏览器 + 本地网络通道，
浏览器和它的数据都放在工具自己的文件夹里（放普通文件夹或 U 盘都行），不碰系统设置，
不往外上传任何东西。用完关掉，电脑上不留常驻服务。

## 它解决什么问题

- **数据隔离**：专用浏览器有自己独立的数据目录，不和日常浏览器混用，
  不登录浏览器账号，历史、Cookie、登录状态只存在工具文件夹里。
- **网络安全**：浏览器的流量只走你自己的节点出去；本工具不改系统代理，
  关掉工具，其他程序的网络不受影响。
- **隐私**：节点信息和浏览器数据只保存在本地，没有任何服务器收集它们。
  本仓库里也只有代码和空白模板，不含任何人的节点信息。

## 支持范围

- 节点协议：支持 sing-box 的协议（内核为官方 sing-box，按需自动下载与更新）。
- SOCKS / HTTP 代理地址也能直接用：
  - 不带账号密码的，浏览器直连，不需要下载内核；
  - 带账号密码的，由内核代登录后转发（浏览器本身不支持 SOCKS 账号认证）。
- 节点链接、订阅链接、一行一个的裸 SOCKS（`地址:端口` 或 `地址:端口:用户名:密码`）都能导入。

## 快速开始（程序版）

1. 把 `foxkit.exe` 放进一个空文件夹。
2. 双击打开，点「导入节点」，把节点链接粘贴进去 —— 当场验格式，
   告诉你成功几条、重复几条、失败几条和失败原因，失败的留在框里改完再导。
3. 在列表里选中一条节点（双击即选中）。
4. 点「启动」。缺的组件（sing-box 内核、专用 Firefox）会从官方来源自动下载准备好；
   只用无密码 SOCKS 时不会下载任何东西。
5. 用完点「停止」，或直接关掉浏览器和内核窗口。

流程是固定的四步：**导入 → 选中 → 测试（可选）→ 启动**。
前一步没完成，后一步的按钮是灰的，旁边会写明点不了的原因。
连通性测试和导入是分开的：测不通只提醒，不拦着启动。

## 脚本版（备用）

`script/` 目录是同一套逻辑的脚本实现（`Start.bat` + `mkconfig.ps1`），
适合连 exe 都不方便运行的环境。脚本不下载任何东西、不绕过系统策略、不藏窗口，
内核和浏览器组件需要先用程序版备好（或手动放到 `script/Surf/` 对应位置）。
细节见 `script/使用说明.md`。脚本版支持的协议比程序版少几个（WireGuard、AnyTLS、SSH 请用程序版）。

## 数据都放在哪

工具文件夹内的 `Surf/` 目录：

| 位置 | 内容 |
|---|---|
| `Surf/nodes.txt`、`Surf/node.txt` | 你的节点（凭证，只存本地，别外发） |
| `Surf/ff-data/` | 专用浏览器的数据（登录状态在这里，敏感程度次于节点） |
| `Surf/core/` | sing-box 内核（官方原版文件） |
| `Surf/Firefox/` | 专用 Firefox 程序文件 |
| `Surf/config.json` | 每次启动按当前节点现生成的配置 |

把整个工具文件夹拷走就能在另一台电脑上接着用；换节点只改节点，不用重装。

## 关于杀毒软件

- 本工具未做商业代码签名，第一次运行时 Windows SmartScreen 可能提示
  「未知发布者」，点「更多信息 → 仍要运行」即可。
- sing-box 这类网络内核会被个别杀毒软件归为「风险工具」提示或隔离
  （不是病毒，是代理类工具的统一待遇）。遇到时把**工具文件夹**加入
  杀毒软件的信任区/白名单即可；发布包附 SHA256，可核对文件完整性。
- 本工具不加壳、不混淆、不自启、不装服务、不改系统代理，行为都在明处。

## 自行构建

需要 Go 1.23+：

```powershell
cd app
go run github.com/josephspurrier/goversioninfo/cmd/goversioninfo@latest -icon=foxkit.ico -manifest=foxkit.manifest -o=foxkit_windows.syso
go build -ldflags="-H windowsgui" -o foxkit.exe .
```

`foxkit_windows.syso`（图标与版本信息）是构建时生成的，不入库；不生成也能构建，只是没有图标。
