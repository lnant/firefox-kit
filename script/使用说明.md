# 脚本版使用说明

同一套工具的脚本实现，备用。双击 `Start.bat` 就能用，流程和程序版一样：
校验节点 → 选一条 → 生成配置 → 启动。

## 运行前准备清单（脚本自己不下载，缺一样跑不起来）

脚本版不下载任何东西。双击 `Start.bat` 之前，先把下面三样备齐。
`Start.bat`、`mkconfig.ps1`、`node.txt` 三个文件要始终放在同一个目录里，不要拆开。

### 1. 浏览器（必需）

- 位置：`Surf/Firefox/`，里面要有 `firefox.exe` 和整套程序文件（只放一个 exe 不行）。
- 怎么来：电脑上装好官方 Firefox，把它的安装目录（一般是
  `C:\Program Files\Mozilla Firefox`）里的**全部文件**复制到 `Surf/Firefox/`。

### 2. 内核（用到协议节点或带账号密码的代理时必需）

- 位置：`Surf/core/`，里面要有 `sing-box.exe` 和 `libcronet.dll`。
- 怎么来：到 sing-box 官方发布页 https://github.com/SagerNet/sing-box/releases
  下载 Windows 版安装包（文件名形如 `sing-box-<版本>-windows-amd64.zip`），
  解压后把这两个文件放进 `Surf/core/`。
- 只用**无账号密码的 SOCKS** 节点时不需要内核，这一项可以跳过。

### 3. 节点（必需）

- 粘贴到本目录的 `node.txt`，一行一条，可以多条、可以带 `#` 注释行。
- `Start.bat` 会先校验并列出可用条数和格式不对的条目，多于一条时让你输序号选。

### 最省事的备法

先用**程序版**在一台能联网、装了 Firefox 的电脑上运行一次，点「准备内核」
和「准备浏览器」，然后把程序版生成的整个 `Surf` 文件夹拷到脚本版目录里，
上面第 1、2 样就都齐了，只剩填 `node.txt`。

### 双击前自检：文件夹应该长这样

```
脚本目录/
├─ Start.bat
├─ mkconfig.ps1
├─ node.txt（已填好节点）
└─ Surf/
   ├─ core/sing-box.exe（+ libcronet.dll）   ← 直连 SOCKS 可没有
   ├─ Firefox/firefox.exe（+ 整套程序文件）
   └─ ff-data/、config.json                 ← 运行时自动生成，不用手动建
```

`Surf`、`Surf/core`、`Surf/Firefox` 这几个文件夹没有就自己新建。

## 使用步骤

1. 双击 `Start.bat`。它先自检：浏览器在不在、PowerShell 脚本策略放不放行
   （第一次可能会问你要不要放行，见后面「第一次运行可能会问一句」一节）。
2. 它校验 `node.txt`，在窗口里列出：可用节点几条、格式不对几条（不对的会
   写明是哪条、什么毛病，已自动跳过）。
3. 可用节点多于一条时，输入序号选一条（直接回车 = 第 1 条）。
4. 需要内核的节点会先生成配置、让内核自检一遍：通过了才继续；
   没通过会保留上一份配置并停下来报错，不会带病启动。
   直连节点不生成内核配置，只写浏览器配置。
5. 启动分两种情况：
   - **需要内核的节点**：先弹出一个标题写着「sing-box 内核（关掉这个窗口就断网）」
     的控制台窗口，然后打开专用 Firefox。
   - **无账号密码的 SOCKS 直连节点**：不弹内核窗口，直接打开 Firefox。
6. 看到 Firefox 打开就可以用了，它的网络走选中的节点；`Start.bat` 自己的
   黑窗口几秒后会自己关，不用管它。

### 怎么确认真的能用

脚本版没有单独的连通性测试功能。启动后在打开的 Firefox 里实际访问一个
网页（或查一下出口 IP）确认；打不开就看下面的报错对照，或换一条节点重跑。

### 停止

- 走内核的节点：**关掉那个内核控制台窗口**就断网，再关掉 Firefox，就全停了。
- 直连节点：直接关掉 Firefox 即可。
- 顺序反了也没事：先关 Firefox、再关内核窗口，结果一样。

### 换节点

先按上面停止，再双击 `Start.bat` 重新选一条就行；想增减节点就改
`node.txt`（一行一条）后再跑。运行期间不能换，要先停。

## 报错对照

| 屏幕上的提示 | 什么意思 / 怎么办 |
|---|---|
| 「还差一步：Surf\Firefox 里没有 firefox.exe」 | 浏览器没备好，按准备清单第 1 样把整套 Firefox 程序文件复制进去 |
| 问要不要把脚本策略设为 RemoteSigned | 第一次运行才有，选 Y 同意（只设一次）；选 N 就退出。详见下面「第一次运行可能会问一句」 |
| 「还是不行，可能被公司/学校策略锁住了」 | 这台电脑的策略被管理员锁死，脚本跑不了，改用程序版 |
| 「node.txt 里没有可用节点」 | 节点没填或格式全不对。看窗口里逐条列出的失败原因，改好 `node.txt` 再跑 |
| 「这个节点需要 sing-box 内核，但 Surf\core 里没有」 | 按准备清单第 2 样放内核；或这条节点改用程序版跑 |
| 「sing-box 自检没通过，已保留上一份配置」 | 这条节点的配置内核不认（可能写法特殊或协议细节对不上），换一条节点，或改用程序版 |
| 提示某协议「脚本版暂不支持，请用程序版」 | 不是你操作错：anytls / wireguard / ssh / hysteria v1 和 XHTTP 传输脚本版确实不支持，换程序版即可 |
| Firefox 打开了但网页打不开 | 节点本身不通的可能性最大。关掉内核窗口和 Firefox，换一条节点重跑；都这样就是节点那边的问题 |

## 第一次运行可能会问一句

PowerShell 脚本默认被系统策略拦着时，`Start.bat` 会问你要不要把
「当前用户」的脚本策略设为 RemoteSigned —— 只需设置一次，同意后以后不再问。
脚本不会自己偷偷绕过策略。

## 支持范围

支持 sing-box 的常见协议（vmess / vless / trojan / ss / hysteria2 / tuic），
以及 SOCKS / HTTP 代理（带账号的经内核转发，不带账号的浏览器直连）。
WireGuard、AnyTLS、SSH 节点脚本版暂不支持，会明确提示你改用程序版。

浏览器数据在 `Surf/ff-data/`，配置在 `Surf/config.json`，都只存本地。

## 搬走与卸载

- **换电脑**：把整个脚本目录拷过去就能用（节点、浏览器数据都在里面），
  前提是准备清单三样都备齐了。
- **卸载**：先关掉内核窗口和 Firefox，再删掉整个脚本目录即可，没装任何东西。
  唯一留在系统里的是第一次运行时你同意过的那次脚本策略设置（当前用户
  RemoteSigned，这是 Windows 的通用设置，不专属于本工具）；想还原就在
  PowerShell 里运行 `Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy Undefined`。
