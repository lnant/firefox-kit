# 脚本版使用说明

同一套工具的脚本实现，备用。双击 `Start.bat` 就能用，流程和程序版一样：
校验节点 → 选一条 → 生成配置 → 启动。

## 先备好两样东西（脚本自己不下载）

1. **内核**：官方 sing-box 的 `sing-box.exe`，放到 `Surf/core/` 里
   （或先用程序版运行一次，它会自动备好，再把 `Surf` 文件夹拷过来）。
2. **浏览器**：把装好的 Firefox 程序文件复制到 `Surf/Firefox/`，
   保证 `Surf/Firefox/firefox.exe` 存在（同样可以从程序版那边拷）。

## 节点放哪

粘贴到本目录的 `node.txt`，一行一条，可以多条、可以带 `#` 注释行。
`Start.bat` 会先校验并列出可用条数和格式不对的条目，多于一条时让你输序号选。

## 第一次运行可能会问一句

PowerShell 脚本默认被系统策略拦着时，`Start.bat` 会问你要不要把
「当前用户」的脚本策略设为 RemoteSigned —— 只需设置一次，同意后以后不再问。
脚本不会自己偷偷绕过策略。

## 支持范围

支持 sing-box 的常见协议（vmess / vless / trojan / ss / hysteria2 / tuic），
以及 SOCKS / HTTP 代理（带账号的经内核转发，不带账号的浏览器直连）。
WireGuard、AnyTLS、SSH 节点脚本版暂不支持，会明确提示你改用程序版。

浏览器数据在 `Surf/ff-data/`，配置在 `Surf/config.json`，都只存本地。
